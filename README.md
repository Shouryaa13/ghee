# Kridhav Ghee Demo

Premium D2C pitch site for Indian ghee brands.

## Next.js app (recommended)

```bash
cd kridhav-web
npm install
npm run dev
```

→ http://localhost:3000

Edit products in `kridhav-web/src/data/products.ts`.  
Images live in `kridhav-web/public/assets/`.

## Legacy single-file demo

`index.html` is the original self-contained HTML version (same design).  
Open it directly in a browser if you need a no-build fallback.
